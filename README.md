## About the Project

**Initium Math.HS** is an educational and productivity platform built for students of the National Mathematical High School of Algiers.

It aims to provide students with a centralized digital workspace to organize their academic life, manage their studies, and monitor their progress.

Rather than relying on scattered notes and traditional to-do lists, Initium brings academic organization and progress tracking into one dedicated platform.

## Features

- **Academic Dashboard:** A centralized overview of your academic activity.
- **Subject Management:** Organize your academic work by subject.
- **Progress Tracking:** Follow your learning progress and completed work.
- **Study Checklist:** Create, manage, and complete study tasks.
- **Personalized Experience:** Access your own academic workspace.
- **Daily Motivation:** Stay focused and maintain consistent study habits.
- **Multilingual Experience:** Support for Arabic and English.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js (compatible with Next.js 15)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/hamzach2301/Initium-math-Hs.git
```

### 2. Navigate to the project

```bash
cd Initium-math-Hs
```

### 3. Install dependencies

```bash
npm install
```


### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

## Deployment

The platform is deployed using **Vercel**.

To deploy your own instance:

1. Import the repository into Vercel.
2. Configure the required environment variables.
3. Connect your Supabase project.
4. Deploy the application.
